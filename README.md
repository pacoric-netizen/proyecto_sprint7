# Datos de anuncios de vehículos
Este trabajo trata del analisis de datos obtenidos de anuncios de vehículos en US, generando un sitio web que muestra gráficas con información relevante, como precios vs kilometraje y distribución del kilometraje.
La URL de la publicación es: https://proyecto-sprint7-29gm.onrender.com
El repositorio se organiza de la siguiente manera: 1 archivo EDA.ipynb dondé se realiza el analisis exploratorio, 1 archivo README con la descripción detallada del proyecto, 1 archivo app.py donde se tiene el código a ejecutar en el sitio web, así como los "commits" de cada cambio considerable.
Para ejecutar la aplicación de manera local, hay que clonar el repositorio de github al equipo donde se ejecutara, abrir la terminal, ir al directorio descargado, y ejecutar el comando: python app.py
